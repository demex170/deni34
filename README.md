# ერთი საღამო — დემე × ნინი

ინტერაქტიული მინი-ისტორია React-ით და Three.js-ით. სცენები, პერსონაჟები და გარემო კოდითაა აგებული; გარე სურათები საჭირო არ არის.

## სწრაფი გაშვება Windows-ზე

ორმაგად დააწკაპუნე `start-site.bat`-ს. პირველად საჭირო პაკეტებს ავტომატურად დააყენებს, შემდეგ კი ბრაუზერში საიტს გახსნის. სერვერის მუშაობისას შავი კონსოლის ფანჯარა ღია დატოვე.

`index.html` პირდაპირ არ გახსნა — ის React + Three.js წყაროს შესასვლელი ფაილია. პირდაპირი გახსნისას ახლა ინსტრუქციას გაჩვენებს, ცარიელ ეკრანს აღარ.

```bash
npm install
npm run dev
```

ტელეფონზე გახსნისას ლანდშაფტურ რეჟიმს გირჩევს. არჩევანი გააკეთე, მიიღე მოწვევა და გაიარე გზა მანქანიდან რესტორნის მაგიდამდე.

## მართვა

- **W A S D / ისრები** — ნინის მოძრაობა
- **Shift** — სირბილი
- **მაუსის დაჭერა და გადაწევა** — კამერის მობრუნება
- **F** — ტელეფონის გახსნა
- **E** — მანქანაში ჩაჯდომა, რესტორანში შესვლა ან მაგიდასთან საუბარი
- **1 / 2 / 3** — დიალოგში პასუხის არჩევა
- **W / S** — მგზავრობისას გაზი / შენელება; **A / D** — საჭის მსუბუქი მოხვევა
- **ტელეფონზე** — ჯოისტიკი, მოქმედების ღილაკი, გაზი/შენელება და კამერის თითით მობრუნება

## GitHub Pages-ზე გამოქვეყნება

პროექტის ფაილები GitHub-ის რეპოზიტორიის root-ში ატვირთე და `main` ან `master` branch-ზე push გააკეთე. `.github/workflows/pages.yml` ავტომატურად ააწყობს და გამოაქვეყნებს `dist` საქაღალდეს.

პირველად რეპოზიტორიის **Settings → Pages → Build and deployment → Source**-ში აირჩიე **GitHub Actions**. Vite-ის `base` რეპოზიტორიის სახელს ავტომატურად მოარგებს.

### Formspree-ით შეკვეთის ელფოსტაზე გაგზავნა

Endpoint პროექტში დაყენებულია: `https://formspree.io/f/xwlpwawv`. სხვა Formspree ფორმის გამოყენებისას შეცვალე `.env.local`-ში `VITE_FORMSPREE_ENDPOINT`, ან GitHub-ზე **Settings → Secrets and variables → Actions → Variables**-ში შექმენი იგივე სახელის variable. Pages workflow-ს build-ისას GitHub variable ავტომატურად ექნება პრიორიტეტი.

შეკვეთა Formspree ანგარიშში მითითებულ და დადასტურებულ email-ზე მივა. ღილაკზე დაჭერისას იგზავნება არჩეული კერძი, სასმელი, კერძის ფასი და შეკვეთის დრო. Endpoint-ის ან ქსელის შეცდომისას თამაში შეკვეთას გაგზავნილად არ აჩვენებს.
